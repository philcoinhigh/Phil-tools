The Line.

A tug of war for two. Both sides secretly choose how hard to pull; the bigger pull moves the coin one place; both pay what they pulled. Get it to your end.

On Solana, the referee is a program built around the upload server that Phil's compiler emits. Nobody can change a move after committing it, and it is Phil's code that checks.

Every step of the match, newest first. On Solana each one is a transaction you can open.

    How a round is refereed

    1. Commit

    Each side sends only a SHA-256 hash of its move: the match, the round, the side, the pull and a random 32-byte secret.

    through Phil's server
    2. Both in

    Reveals open only when both hashes are recorded. Until then nobody, including the referee, knows a pull.

    our code
    3. Reveal

    Each side uploads the move itself. It must declare the committed hash, and Phil's server checks the bytes against it. A changed pull does not match.

    checked by Phil's server
    4. Play

    With both pulls open the program applies the rules: move the coin, charge both sides, check for a win, open the next round.

    our code

    A side that commits and does not reveal in time forfeits. That is what stops a player who sees they are about to lose a round from simply walking away.

    Matches on Solana

    Every night two practice players play a whole match on devnet and the result is recorded here.

      Before you rely on it

      • Nothing is staked, and nothing can be. A match holds no SOL beyond its own account's rent, and the program has no instruction that pays anyone. This is a game and a demonstration, on a test network.
      • It has not been audited, and the program can still be replaced. On devnet our deploy key can upgrade it.
      • What Phil's code checks, and what it does not. Phil's server checks each upload's handshake, its policy, and that the bytes match the hash they declare. The rules of the game, the clock and who may move are our C code, which is not Phil and is not verified.
      • Against the bot, your browser holds both keys. The bot commits its move on Solana before you choose yours, so it cannot react to you, but it is a practice opponent and not proof of anything. Against a friend, each side holds only its own key.
      • If you close the page mid-round you may forfeit. Your secret for the round lives in this browser. Come back in time and the page picks the match up again.
      • A match's account costs about 0.003 devnet SOL in rent, which is not returned.

      Where this comes from

      The game and its rules ("duels-1") are from Highwire by HigherMaestro (MIT), built for AI agents on higher.fun. Phil's repository has an example that writes one player's side of a round as a Phil protocol and leaves the referee outside Phil. This page is a referee for that round with Phil's compiled server inside it. It is a separate program from Highwire's, with no stakes.
