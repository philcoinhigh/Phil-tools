Same Phil, every chain.

One program compiled from Phil, answering on Solana, Robinhood Chain and BNB Chain. Send all of them the same upload and compare what comes back.

Nothing to connect and nothing to pay: each chain is asked with a read-only call to its live node.

Ask every chain

Your note is sealed with its SHA-256 and handed to Phil's upload server, the same compiled code on every machine below. It checks the handshake, the policy, and that the bytes still match their seal.

How one program gets onto different chains

1. Phil compiles once

Phil's compiler turns its upload server into LLVM, a form that can be built for many kinds of machine.

Phil
2. Solana runs it natively

That code is built for Solana's own machine and deployed as an ordinary Solana program.

our build
3. Ethereum-style chains run it through a small machine

Phil has no output for these chains. So the same code is built for RISC-V, a simple chip, and one contract plays that chip, instruction by instruction. That contract works on any such chain.

our contract

Before you rely on it

  • This is a demonstration on test networks. Nobody independent has reviewed it, and it holds nothing of value.
  • On Ethereum-style chains Phil's code is interpreted, not native. That costs far more gas than a contract written for the chain: about 650,000 gas for one upload. A real EVM backend for Phil would be the proper answer, and that is for Phil's author to build.
  • What is Phil, and what is ours. The upload server is Phil's compiled code, unchanged. The runtime it calls, the Solana wrapper and the RISC-V interpreter contract are ours, are not Phil, and are not verified.
  • The same code is not the same guarantee. Each chain has its own rules, fees and risks. This shows the logic is portable, and nothing more.
  • It is not a launchpad and launches nothing. It answers one question: does the same Phil program give the same answer everywhere.
  • The program keeps no state. An accepted note is counted on the Ethereum-style chains and otherwise kept nowhere.
