An OTC desk written in Phil

A maker locks tokens with the desk and names a price. A taker pays that price or walks away. The desk passes each coin on and keeps only its fee.

Tokens and cash are linear values in the program, so Phil rejects any desk that keeps, copies or loses one. Set the terms and run the real program below.
