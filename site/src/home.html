Try Phil. Learn Phil. Build with Phil.

Phil is a programming language by Meredith Patterson where a value can't be copied or lost, programs talk by following a script, and promises in the code are checked.

These are open-source tools from the Philcoin community that make the language easier to pick up today, and that will grow with it.

Where this is going

  

    
Now
Tools that work with the Phil that exists: read it, run it in a simulator, learn it.

    
As Phil grows
Each new language feature lands in the tools. The OTC desk moves from simulation toward real settlement.

    
Later
Dashboards and apps built on Phil. Any paid tools fund Phil and Philcoin adoption.

  

  
The simulator is our own reading of the published grammar and tour. It is not the official Phil implementation, and a clean run here is not a proof. Phil itself lives at github.com/abiggerhammer/phil.
