    Burn vault

    A vault is an address that collects SOL. Whoever burns the set amount of this coin takes everything in it. It has no owner and no way to withdraw, so the only way the SOL leaves is by the coin being burned.

      Giveaway

      The entry list is locked on Solana first. Then a block that does not exist yet picks the winner, so nobody can choose it, including you. The giveaway gets its own page that anyone can check.

      Connect a wallet above to run a giveaway.

      A longer wait gives people time to see the locked list before the draw. You sign twice: once to lock, once to draw.

        Before you rely on it

        • This is on devnet and has not been audited. Everything here is tested against Solana's real token program and runs on devnet every night, but nobody independent has reviewed it. Do not treat it as safe for real value yet.
        • The programs can still be replaced. On devnet our deploy key can upgrade them, which is how we fix things while building. "Nobody can unlock early" and "no way to withdraw" become fully true only once a program is made permanent. We will say so here when it is.
        • Anyone can open a vault for any coin. A vault listed here was not necessarily opened by the coin's team. Read its rule before sending it fees: a vault with a tiny burn amount pays out for burning almost nothing.
        • A giveaway picks a winner. It does not hold or send a prize. Whoever runs it decides who is on the list and pays the prize themselves. Share the giveaway's link before the draw.
        • Locks, burns and giveaways do not make a coin safe or valuable. They show exactly what they say and nothing more.

        Where Phil is in this

        Each action here is an upload through UploadServer, the function Phil's compiler backend emits, running inside three programs on Solana. Phil's code checks the handshake, the policy and that the bytes match their declared SHA-256, and only then does the program act. The parts that touch coins (the escrow, the burn, the draw) are ours and are not Phil.
